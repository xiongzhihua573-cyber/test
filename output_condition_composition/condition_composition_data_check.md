## 共同条件与逐单元评分来源

四个情景均采用2024年 LOCF 初始评分，59个检测单元，2025—2039年15个年末状态，年下降量 d=0.65分/年，养护恢复量 R=6分。共同规划条件为年度最多8个行动、同一单元两次行动间隔至少3年、每单元最多3次行动；养护可行性要求所有单元评分高于60，且每年至少57/59个单元高于75。无养护作为固定对照保留其不满足管理条件的结果。

原始来源为冻结的最终15年项目 `manuscript_sci_stage12`。随包 `source_data/` 保存来源文件的逐字节副本及 `source_provenance.json` SHA-256 清单，包括初始评分和面积、资源档汇总、30次运行记录、代表方案年度结果、无养护年度结果，以及上述三个代表方案 JSON 中原封不动的59×15二元行动矩阵。

精简项目中没有完整保存三个代表方案的59×15逐单元年末评分表。本次按指令允许的路径，固定已有行动，使用原始状态递推代码准确复算，而非根据平均评分或图形估算等级人数：

`S[i,t] = min(100, max(0, S[i,t-1] - 0.65) + 6 * action[i,t])`

每年的下降在前，已保存的当年行动恢复在后。2024初始状态不作为图中的第一个规划年；第一次递推对应2025年末。

随包 `original_area_model_stage7.py` 是原历史代码的完整未改副本，SHA-256 为 `cf8f22ae3f5c904cc8e1e201adb56be847b9eb562427fea60d48e558b6a773d1`。原代码来自 `manuscript9.zip` 中的 `manuscript_stage9/source_code/small_paper_cn/main_experiments_stage7/scripts/area_model.py`。该历史文件默认期限为20年；准备脚本仅提取其中 `_inputs`、`resource_tolerance`、`simulate_actions` 三个审计函数，将期限及年份按最终运行元数据绑定为15年、2025—2039。评分递推不变，输入始终是原始15年行动矩阵，未截取或重新解码20年决策。

准备脚本不执行模型拟合、GJO、搜索、修复或决策解码。原始审计递推与独立的逐单元逐年度标量递推在全部3540个评分上逐值完全相同；并核对原方案所有可用标量指标、45条养护年度记录及15条无养护年度记录。完整复算结果保存在 `unit_year_scores.csv`。

## 严格分级与数量核验

| 模型评分类别 | 区间 |
|---|---|
| 1类 | 90 < S ≤ 100 |
| 2类 | 75 < S ≤ 90 |
| 3类 | 60 < S ≤ 75 |
| 4类 | 40 < S ≤ 60 |
| 5类 | 0 ≤ S ≤ 40 |

分级使用原始浮点评分，不先四舍五入，不添加 epsilon。90属于2类，75属于3类，60属于4类，40属于5类；0属于5类，100属于1类。边界和紧邻边界的可表示浮点数均单独核验。当前实际评分没有距40、60、75、90不超过1e-10的值。原模型管理可行性审核中的1e-8容差不用于等级分类。

每一情景每一年按59个单元逐个分级。`count / 59 × 100` 为对应比例；共4×15×5=300条构成记录、4×59×15=3540条单元评分记录。每个情景年度五类数量合计59、比例合计100%（允许1e-12浮点合计误差）。CSV 包含 `scenario, B, year, grade, count, percentage, maintenance_actions`，并保留初始条件、d、R和方案标识。

## 结果限制与图的解释

无养护对照从2036年起不满足“每年至少57个单元评分高于75”的管理条件，最少54个；全期最低评分仍为71.43。它是要求展示的固定零行动对照，不能称为管理可行策略。三个养护代表方案均通过年度能力、间隔、次数、归一化资源及管理条件审核。

所有情景、所有年份的4类和5类数量均为0。图例完整保留5个类别，数据不人为增加较差等级。2039年1—5类人数分别为：无养护 `[0,54,5,0,0]`，低资源 `[19,39,1,0,0]`，中等资源 `[40,18,1,0,0]`，高资源 `[58,1,0,0,0]`。等级构成不能展示同一等级区间内部的连续评分差异，如需说明可与现有平均评分曲线配套使用。

两套图使用完全相同的年度数据、分级区间、坐标范围、顺序及纯色配色。养护面板下方细条显示当年执行养护的检测单元数，不表示全桥网络统一养护。面积图仅以直线连接15个年度的真实构成比例，不平滑、不额外计算年内状态。建议优先使用柱状图，以保留离散年度含义；最终采用哪一版由作者决定。

参考 Liu等（2025），Automation in Construction 174, 106175，第10页Fig.17，仅借鉴多情景等级构成比较的表达形式。未使用参考论文的任何数值、策略、半马尔可夫模型或研究结论。本结果是模型情景下检测单元连续评分的区间分类，不能表述为实测等级转移概率，也不等同于完成规范全部项目和控制指标核查后的正式桥梁技术状况评定。
