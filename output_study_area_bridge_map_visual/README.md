# 甬台温高速宁波段：SCI风格示意稿

`study_corridor_sci_style_preview.png` 为依据用户提供的第二张地图截图、参考第一张SCI地图风格生成的视觉示意稿。原尺寸1536×1024像素。

采用浅色路网、绿色位置标记、蓝灰色高速走廊及红色虚线示意范围，保留底图中7个位置标记的示意关系。图中红线不是经过测量的工程或行政边界；图像经过生成式重绘，道路细节不能作为可测量的GIS线位。

这7个标记尚未与论文的59个检测单元逐一对应，不能据此认定59个桥址完成定位。该图用于审阅版面和表达方式，不能替代精确桥位分布图或带校准比例尺的正式地理底图。图内已注明“据底图示意”及桥位、范围待资料核验。

待取得定检报告、可核验桥位坐标或经标定的主线及各匝道路线几何后，再进行定位核验和正式制图。原论文和既有研究数据未修改。
