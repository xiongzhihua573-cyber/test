## 上传范围说明

完整项目ZIP包含原始论文、修改指令、两份原始Excel和两份参考PDF。GitHub仓库的可见性决定谁能访问提交后的文件。在获得用户对该上传范围的明确授权前，只在本地仓库准备，不向GitHub推送。

## 提交到GitHub后如何下载

1. 打开仓库 https://github.com/xiongzhihua573-cyber/test 。
2. 选择包含本次交付提交的分支，进入 `deliverables/stage1/`。
3. 点击所需文件，通过GitHub文件页面的下载按钮（Download raw file）下载。
4. 也可在仓库首页使用 `Code → Download ZIP`，解压后在此目录取出交付文件。

目录准备完成不代表已上传。应以实际推送成功、且GitHub上能看到该提交为准；没有推送的分支无法从GitHub下载。
